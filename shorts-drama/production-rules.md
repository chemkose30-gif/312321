# 시니어 숏드라마 제작 규칙

Claude가 힉스필드(Higgsfield)로 영상을 만들 때 매번 이 규칙을 그대로 따른다.
출연진과 배우 이미지 프롬프트는 `cast.md`에 있다.

## 1. 영상 생성 고정 설정

| 항목 | 값 |
|---|---|
| 모델 | Seedance 2.5 (`seedance_2_5`) |
| 모드 | `omni_reference` (배우 기준 이미지를 참조로 넣음) |
| 화면 비율 | 9:16 |
| 장면 길이 | 12초 |
| 음성 | `generate_audio: true` (한국어 대사 자동 생성) |
| 최종 화질 | 1080p |
| 비트레이트 | `high` |

## 2. 초안 → 확정 절차

1. 장면 5개를 **480p 초안**(`draft: true`)으로 생성한다.
2. 아래 품질 기준에 걸리는 장면만 다시 생성한다.
3. 통과한 장면만 `draft_job_id`로 **1080p 확정**한다. (초안 생성 후 7일 이내)

## 3. 공통 프롬프트 문구

모든 장면 프롬프트 끝에 붙인다.

```
Korean drama style, photorealistic, cinematic lighting, vertical 9:16 framing, all dialogue spoken in natural Korean
```

## 4. 품질 기준 (다시 생성하는 경우)

- 배우 얼굴이 기준 이미지와 달라 보임
- 손가락, 팔다리 등 신체가 어색함
- 한국어 발음이 부정확하거나 입 모양이 대사와 맞지 않음
- 대사가 잘리거나 다른 인물이 말함
- 화면에 깨진 글자가 나옴

## 5. 편집 규칙

- 장면 5개를 이어 붙여 약 60초로 만든다.
- 자막은 **크게, 고대비**(흰 글씨 + 검은 테두리), 한 화면에 1~2줄.
- 배경음악은 대사를 가리지 않게 낮게 깐다.
- 마지막 장면에 시리즈명 또는 다음 편 안내 문구를 넣는다.

## 6. 크레딧 규칙

- 생성 전에 예상 크레딧을 먼저 확인하고, **승인을 받은 뒤에만** 생성한다.
- 재생성이 같은 장면에서 3번 넘게 실패하면 멈추고 프롬프트를 수정한다.

## 7. 출연 규칙

- 연속극 출연진은 연속극에만 출연한다. 단편에는 출연시키지 않는다.
- 단편 배우풀은 같은 배우를 최소 1주 간격으로 출연시킨다.
- 착한 역과 악역은 바꿔 맡겨도 되지만, 연달아 올리는 단편에서는 피한다.

## 8. 업로드

- 품질 확인은 사람이 직접 한다.
- 틱톡은 연결 후 Claude가 업로드할 수 있다. 유튜브 쇼츠는 직접 올린다.
