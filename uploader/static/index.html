업로드는 서버에 한 번만, 전송은 모든 채널에 동시에.

계정을 원하는 만큼 연결

플랫폼별로 아이디를 여러 개 붙일 수 있습니다. 계정마다 별칭을 달아두면 목록에서 바로 구분됩니다.

영상과 내용 작성

영상을 끌어다 놓고 제목·설명·해시태그를 한 번만 입력하세요. 글자수 제한은 자동으로 맞춰집니다.

올릴 채널 체크 후 게시

선택한 모든 계정으로 동시에 전송하고, 채널별 진행률과 결과 링크를 실시간으로 보여줍니다.

여러 아이디를 쓰는 사람을 위한 기능

브랜드 계정, 부계정, 클라이언트 채널을 한 화면에서 관리합니다.

👥

계정 무제한 추가

같은 플랫폼에 아이디를 몇 개든 연결할 수 있습니다. 메타 계정은 로그인 한 번으로 보유한 페이지와 인스타 계정이 한꺼번에 등록됩니다.

✅

채널 다중 선택

업로드할 때 계정별 체크박스로 고르고, 플랫폼 단위 전체 선택도 한 번에 됩니다.

🏷️

별칭으로 구분

'메인 채널', 'B사 클라이언트'처럼 이름을 붙여두면 계정이 많아져도 헷갈리지 않습니다.

⚡

동시 전송

선택한 채널로 병렬 업로드합니다. 한 채널이 실패해도 나머지는 그대로 게시됩니다.

🎚️

채널별 공개 설정

유튜브 공개범위·카테고리, 틱톡 공개 대상과 댓글/듀엣 설정을 플랫폼마다 따로 지정합니다.

🔐

토큰 암호화 보관

액세스 토큰은 암호화해 내 서버 SQLite에만 저장하고, 연결 끊기로 언제든 삭제할 수 있습니다.

3올릴 채널 선택

계정마다 체크해서 고르세요. 자주 쓰는 조합은 세트로 저장해 한 번에 선택할 수 있습니다.

계정 관리

플랫폼마다 아이디를 원하는 만큼 추가하세요. 내 아이디 추가로 유튜브·인스타 아이디를 직접 적어 목록을 먼저 만들고, 로그인 연결을 마치면 그 아이디로 실제 게시가 시작됩니다.

채널 세트

자주 함께 올리는 계정을 묶어두면 업로드 화면에서 클릭 한 번으로 전부 선택됩니다. (예: 브랜드A 전체 = 유튜브 메인 + 틱톡 부계정 + 인스타)

비밀번호 잠금

이 앱은 로그인해야만 들어올 수 있습니다. 비밀번호는 해싱해서 저장되고, 서버 소유자만 바꿀 수 있습니다.

사이트 소유권 확인 파일

틱톡·메타가 "이 주소가 당신 것인지" 확인하려고 파일을 요구할 때 씁니다. 콘솔이 알려준 파일 이름과 내용을 그대로 넣고 저장하면, 그 주소로 즉시 공개됩니다.
