0. 압축을 반드시 "풀어야" 합니다
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ZIP 을 더블클릭해서 열린 창에서 바로 실행하면 안 됩니다.
  ZIP 파일 오른쪽 클릭 → [압축 풀기] → 나온 폴더로 들어가세요.

1. 실행
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  윈도우 :  run.bat  더블클릭
  맥     :  run.command  더블클릭
            (경고가 뜨면 오른쪽 클릭 → 열기 → 열기)

  · Python 이 없으면 윈도우 10/11 에서는 자동으로 설치를 시도합니다.
    설치 창이 뜨면 "예"를 누르고, 끝나면 run.bat 을 한 번 더 실행하세요.
  · "Windows의 PC 보호" 파란 경고 → [추가 정보] → [실행]
  · 처음 한 번은 준비에 1~5분. 이후에는 몇 초.

  준비가 끝나면 브라우저가 자동으로 열립니다.
  안 열리면 주소창에 직접:   http://localhost:8100

  끄기 : 윈도우는 창 닫기 / 맥은 Ctrl+C

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 잘 안 될 때
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  창은 자동으로 닫히지 않습니다. [ERROR] 로 시작하는 줄과
  그 아래 한글 안내를 읽어보세요.

  · Running from inside the ZIP  → 0번(압축 풀기)을 하세요.
  · Python not found             → 창을 닫고 run.bat 을 한 번 더 실행.
                                   그래도 안 되면 python.org 에서 설치하며
                                   "Add python.exe to PATH" 체크.
  · Could not create .venv       → 폴더를 바탕화면으로 옮긴 뒤 다시 실행.
                                   (OneDrive·네트워크 드라이브에서 자주 실패)
  · Package installation failed  → 인터넷/방화벽 확인 후 다시 실행.
  · 포트가 이미 사용 중            → 명령 프롬프트에서:  run.bat 8200

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2-1. 24시간 켜두고 싶다면 (윈도우)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  run.bat 이 정상적으로 뜨는 걸 확인한 뒤 창을 닫고,
  service-install.bat 를 실행하세요.

  · 컴퓨터를 켜면 창 없이 자동으로 시작됩니다.
  · 서버가 죽으면 5초 뒤 자동으로 다시 켜집니다.
  · 기록 : data\server.log
  · 해제 : service-uninstall.bat

  ※ PC가 절전(대기 모드)로 들어가면 서버도 멈춥니다.
    [설정]-[시스템]-[전원] 에서 절전을 "안 함" 으로 두세요.

3. 브라우저가 열린 다음
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ① [계정 관리] → "비밀번호 잠금" 에서 비밀번호 설정
  ② [계정 관리] → "+ 내 아이디 추가" 로 아이디 등록
  ③ [계정 관리] → "채널 세트" 로 자주 쓰는 조합 묶기
  ④ [업로드] 에서 영상 → 제목/해시태그 → 채널 체크 → 게시

  ※ API 키 입력 전에는 '데모 모드' 입니다. 화면과 흐름은 그대로지만
    실제 전송은 하지 않습니다. 실제 게시 설정은 README.md 참고.
