# 금(XAUUSD) 자기 발전 AI 트레이더

5분봉 단타 전략을 **스스로 탐색하고, 검증하고, 더 나은 것으로 교체**하는 파이썬 도구입니다.
주문을 직접 넣지 않습니다. 백테스트, 발전 기록, 현재 신호(진입·손절·익절가)까지만 제공합니다.

## 어떻게 "발전"하나

```
데이터 ─┬─ 학습 구간 (앞 70%) ── 유전 알고리즘으로 파라미터 탐색 ── 상위 5개 후보
        │                                       └─ 후보별 "이기는 신호" 학습 필터(로지스틱 회귀)
        └─ 검증 구간 (뒤 30%, 학습에 안 쓴 기간)
                 기존 챔피언 vs 도전자 성적 비교
                 도전자가 더 낫고 검증에서도 수익 → 교체, 아니면 유지
```

- **전략 뼈대**: 추세 EMA, EMA 9/21 정배열, VWAP, 스토캐스틱 되돌림 진입, ATR 손절, 손익비 익절, 세션 시간 필터
- **진화 대상**: EMA 길이, 스토캐스틱 기준, 손절 폭, 손익비, 최대 보유 시간, 거래 시간대, VWAP/숏 사용 여부
- **학습 필터**: 과거 거래의 특징(스토캐스틱, EMA·VWAP 이격, 변동성, 시간대, 기울기)으로 승리 확률을 추정하고 낮은 신호는 건너뜀
- **과최적화 방지**: 검증 구간 비교, 최소 거래 수, 낙폭 페널티, 스프레드와 슬리피지 반영, 같은 봉에서 손절과 익절이 모두 닿으면 손절로 처리
- 결과는 `state/champion.json`(현재 전략)과 `state/history.jsonl`(사이클별 채택·기각 사유)에 저장

## 사용법

```bash
pip install -r requirements.txt

# 1) 데이터 준비: MT5 → 기호 XAUUSD → 차트 M5 → 파일 > 저장(CSV) 또는 TradingView 내보내기
python trader.py improve  --csv xauusd_m5.csv     # 발전 1사이클 (매일·매주 반복 실행)
python trader.py backtest --csv xauusd_m5.csv     # 현재 챔피언 성적
python trader.py signal   --csv xauusd_m5.csv     # 마지막 봉 기준 신호
python trader.py history                          # 발전 기록

# 그 밖의 데이터 원본
python trader.py improve --yf     # yfinance 금 선물(GC=F) 최근 60일 5분봉
python trader.py improve --demo   # 합성 데이터 (코드 동작 확인용, 결과에 의미 없음)
```

옵션: `--spread 0.3 --slippage 0.1` (브로커에 맞게), `--pop 24 --gens 12` (탐색량), `--min-trades 30`

자동으로 계속 발전시키려면 cron 등으로 주기 실행합니다. 예: 매일 새 CSV를 받아 `improve` 실행

## 꼭 알아둘 한계

- 백테스트 성적이 실전 성적은 아닙니다. 검증 구간이 하나라서, 후보 여러 개 중 하나를 고르는 과정에서도 약간의 운이 섞입니다.
  최소 몇 주는 **데모 계좌에서 `signal` 결과를 따라 해 보고** 판단하세요.
- 경제지표(CPI, NFP, FOMC) 발표는 따로 거르지 않습니다. 해당 시간에는 신호를 무시하는 것을 권합니다.
- 데이터가 적으면(예: 1~2주) 거래 수가 부족해 의미 있는 결론이 나오지 않습니다. 최소 2~3개월치 5분봉을 권합니다.
- 투자 조언이 아니며, 레버리지 상품은 원금 이상 손실이 날 수 있습니다.
