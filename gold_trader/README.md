# 금(XAUUSD) 자기 발전 AI 트레이더

금 단타 전략을 **스스로 탐색하고, 검증하고, 더 나은 것으로 교체**하는 파이썬 도구입니다. 봉 단위(1·5·15분)도 AI가 고릅니다.
주문을 직접 넣지 않습니다. 백테스트, 발전 기록, 현재 신호(진입·손절·익절가)까지만 제공합니다.

## 어떻게 "발전"하나

```
1·5·15분봉 데이터 (같은 기간으로 맞춤)
  봉 단위마다 ─┬─ 학습 구간 (앞 70%) ── 유전 알고리즘으로 파라미터 탐색 ── 상위 5개 후보
              │                                     └─ 후보별 "이기는 신호" 학습 필터(로지스틱 회귀)
              └─ 검증 구간 (뒤 30%, 학습에 안 쓴 같은 기간) ── 봉 단위별 최고 후보
  세 봉 단위의 최고 후보 중 1위 vs 기존 챔피언
  도전자가 더 낫고 검증에서도 수익 → 교체 (봉 단위 포함), 아니면 유지
```

- **봉 단위 선택**: 거래당 위험이 같으므로, 같은 검증 기간의 손익(R 합계, 낙폭 반영)으로 공정하게 비교합니다.
  1분봉은 스프레드 부담과 노이즈가 커서 그만큼 불리하게 평가되고, 15분봉은 거래 수가 적으면 감점됩니다.
- **실제 스프레드**: MT5에서 최근 하루 스프레드 중앙값을 읽어 학습과 모의매매 비용에 씁니다 (`--spread`로 직접 지정 가능).

- **전략 뼈대**: 추세 EMA, EMA 9/21 정배열, VWAP, 스토캐스틱 되돌림 진입, ATR 손절, 손익비 익절, 세션 시간 필터
- **진화 대상**: EMA 길이, 스토캐스틱 기준, 손절 폭, 손익비, 최대 보유 시간, 거래 시간대, VWAP/숏 사용 여부
- **학습 필터**: 과거 거래의 특징(스토캐스틱, EMA·VWAP 이격, 변동성, 시간대, 기울기)으로 승리 확률을 추정하고 낮은 신호는 건너뜀
- **과최적화 방지**: 검증 구간 비교, 최소 거래 수, 낙폭 페널티, 스프레드와 슬리피지 반영, 같은 봉에서 손절과 익절이 모두 닿으면 손절로 처리
- 결과는 `state/champion.json`(현재 전략)과 `state/history.jsonl`(사이클별 채택·기각 사유)에 저장

## 내 PC의 MT5로 1주일 모의매매 기록 남기기 (윈도우)

이 프로그램은 MT5에서 **가격만 읽고 주문은 넣지 않습니다.** 실계좌에 로그인돼 있어도 안전하며, 매매는 가상 잔고(기본 10,000$)로 기록됩니다.

1. [Python](https://www.python.org/downloads/) 설치 (설치 화면에서 "Add python.exe to PATH" 체크)
2. 이 `gold_trader` 폴더를 PC에 내려받기
3. MT5를 켜고 로그인한 상태로 둔다. `도구 > 옵션 > 전문가 조언자`에서 "알고리즘 트레이딩 허용" 체크
4. `start.bat` 더블클릭
   - 처음에는 MT5 과거 1·5·15분봉으로 전략과 봉 단위를 학습
   - 이후 1분마다 확인해, 선택된 봉 단위의 봉이 마감될 때 매수·매도를 `state\journal.csv`에 기록 (엑셀로 열림)
   - `reports\날짜_주간기록.md`에 최근 7일 기록이 매번 갱신됨
   - **매주 수요일·토요일 오전 10시 이후(PC 시간) 각 한 번** 스스로 새 전략을 찾아 더 나으면 교체
     (수요일 오전은 금 거래가 한산한 아시아 시간대, 토요일은 장이 닫힌 뒤)
5. PC와 MT5를 1주일 켜 두기 (절전 모드 끄기). 창을 닫았다가 다시 실행해도 이어서 기록됨

심볼명이 다르면 `python trader.py run --mt5 --symbol XAUUSD` 처럼 시장 감시 창의 이름을 그대로 넣습니다.
서버 시간은 자동 감지하고, 장이 닫혀 있을 때는 `--server-offset 3` 처럼 직접 지정합니다.
옵션: `--balance 10000` (가상 잔고), `--risk 3` (거래당 위험 %), `--max-positions 5`, `--leverage 100`, `--improve-days 2,5 --improve-hour 10` (자기 발전 요일·시각, 0=월 ... 6=일)

## 24시간 켜 두기 (자동 시작·자동 재시작)

- `auto_demo.bat`/`start.bat`은 프로그램이 오류로 멈추면 **30초 뒤 자동으로 다시 시작**합니다
  (MT5가 아직 안 켜진 경우 포함). 창을 닫거나 Ctrl+C로 멈추면 재시작하지 않습니다.
- `setup_autostart.bat` 더블클릭: 윈도우 로그인 1분 뒤 `auto_demo.bat` 자동 실행 + 전원 연결 시 절전 끄기.
  "실패"가 나오면 우클릭 → 관리자 권한으로 실행. 해제는 `remove_autostart.bat`.
- MT5는 프로그램이 연결할 때 스스로 실행합니다. MT5 로그인 때 "비밀번호 저장"을 체크해 두세요.
- 같은 프로그램을 두 번 실행하면 두 번째는 바로 멈춥니다 (주문 중복 방지).
- 정전 후 PC가 스스로 켜지게 하려면 BIOS의 "AC 전원 복구(Restore on AC Power Loss)"를 켜고,
  윈도우 자동 로그인을 설정해야 합니다. 완전한 24시간 운영은 윈도우 VPS를 권합니다.

## 대시보드

`start.bat`이나 `auto_demo.bat`을 실행하면 `reports\dashboard.html`이 브라우저에 열리고 1분마다 갱신됩니다.
따로 만들려면 `python trader.py dashboard --mt5`.

- **계좌**: 잔고, 평가금, 평가 손익, 사용·가용 증거금, 증거금 수준, 레버리지, 데모/실계좌 표시
- **오늘 거래 / 전체 거래**: 거래 수(매수·매도), 승패, 승률, 손익, 손익비, 평균 이익·손실, 최대 낙폭, 최고·최악 거래
- **차트**: 누적 손익, 최근 30일 일별 손익 (마우스를 올리면 값 표시)
- **보유 포지션, 거래 기록**, **AI 전략 상태**(세대, 봉 단위, 손절·익절 배수, 학습 일정, 봉 단위별 점수, 발전 기록)
- 위쪽 탭으로 **AI 자동매매 / 계좌 전체 / 모의매매**를 바꿔 봅니다

## 특정 계좌로 자동 로그인 (선택)

MT5에 이미 로그인돼 있으면 필요 없습니다. 데모 계좌로 확실히 고정하고 싶으면
`mt5_config.example.json`을 `mt5_config.json`으로 복사해 로그인 번호·비밀번호·서버를 적습니다.
이 파일은 PC에만 남고 GitHub에는 올라가지 않습니다 (`.gitignore`).

## 자동매매 (MT5에 실제 주문)

`auto_demo.bat` 더블클릭 또는 `python trader.py auto --mt5`

| 설정 | 기본값 | 옵션 |
|---|---|---|
| 거래당 위험 | 잔고의 3% | `--risk 3` |
| 동시 최대 포지션 | 5개 (같은 방향만 추가) | `--max-positions 5` |
| 레버리지 | 100배 (모의매매 증거금 계산용, 자동매매는 브로커 실제 증거금 사용) | `--leverage 100` |
| 하루 손실 한도 | 10% 도달 시 그날 신규 진입 중단 | `--daily-loss 10` |
| 1회 최대 랏 | 0.10랏 | `--max-lot 0.1` |

- **데모 계좌에서만 주문합니다.** 실계좌는 `--allow-real`을 직접 붙여야 동작합니다.
- 손절·익절을 주문과 함께 브로커 서버에 걸어서, PC가 꺼져도 손절·익절은 실행됩니다. 시간 초과와 금요일 청산은 프로그램이 켜져 있어야 합니다.
- 매직 넘버 `20261015`로 이 프로그램의 주문만 관리합니다. 다른 EA와 같은 계좌·심볼에서 동시에 돌리지 마세요.
- 폴더에 `STOP` 파일을 만들면 신규 진입을 멈춥니다. 기존 포지션은 손절·익절로 정리됩니다.
- 기록: `state\live_journal.csv` (실제 주문), `state\journal.csv` (같은 설정의 모의매매)
- 잔고가 작아 최소 0.01랏으로도 위험이 3%를 넘으면 진입하지 않습니다. 금 0.01랏에 손절 4달러면 잔고 약 130달러 이상, 100배 레버리지로 5개 동시 보유는 증거금 약 210달러 이상 필요합니다.

**주의:** 3% × 5개면 동시에 잔고의 15%가 위험에 노출됩니다. 모두 금이라 함께 손절될 가능성이 큽니다.

### 금 전용 규칙
- 1랏 = 100온스. 손절 폭에 맞춰 잔고의 `--risk`%만 잃도록 랏 계산 (0.01랏 미만이면 진입 안 함)
- 미국 고용지표(NFP, 매월 첫 금요일)와 FOMC 발표 전후 30분은 진입 금지. CPI 등은 `events.csv`에 날짜 추가
- 금요일 19시(UTC) 이후 신규 진입 금지, 20:45에 보유 포지션 청산 (주말 갭 회피)

## 사용법

```bash
pip install -r requirements.txt

# 1) 데이터 준비: MT5 → 기호 XAUUSD → 차트 M5 → 파일 > 저장(CSV) 또는 TradingView 내보내기
python trader.py improve  --csv xauusd_m5.csv     # 발전 1사이클 (매일·매주 반복 실행)
python trader.py backtest --csv xauusd_m5.csv     # 현재 챔피언 성적
python trader.py signal   --csv xauusd_m5.csv     # 마지막 봉 기준 신호
python trader.py history                          # 발전 기록

# 그 밖의 데이터 원본
python trader.py run --mt5          # 실시간 모의매매 (start.bat 이 하는 일)
python trader.py report             # 최근 7일 주간 리포트
python trader.py improve --yf     # yfinance 금 선물(GC=F) 최근 60일 5분봉
python trader.py improve --demo   # 합성 데이터 (코드 동작 확인용, 결과에 의미 없음)
```

옵션: `--timeframes 1,5,15` (봉 단위 후보), `--spread 0.5 --slippage 0.1` (생략 시 MT5 실제 스프레드), `--pop 24 --gens 12` (탐색량), `--min-trades 30`

자동으로 계속 발전시키려면 cron 등으로 주기 실행합니다. 예: 매일 새 CSV를 받아 `improve` 실행

1분봉 후보를 제대로 비교하려면 MT5 `도구 > 옵션 > 차트 > 차트 최대 봉 수`를 100000 이상으로 두세요.
1분봉 데이터 기간이 다른 봉 단위의 60%보다 짧으면 그 회차 비교에서 빠집니다.

## 꼭 알아둘 한계

- 백테스트 성적이 실전 성적은 아닙니다. 검증 구간이 하나라서, 후보 여러 개 중 하나를 고르는 과정에서도 약간의 운이 섞입니다.
  최소 몇 주는 **데모 계좌에서 `signal` 결과를 따라 해 보고** 판단하세요.
- 경제지표(CPI, NFP, FOMC) 발표는 따로 거르지 않습니다. 해당 시간에는 신호를 무시하는 것을 권합니다.
- 데이터가 적으면(예: 1~2주) 거래 수가 부족해 의미 있는 결론이 나오지 않습니다. 최소 2~3개월치를 권합니다.
- `--csv`/`--yf` 데이터는 원본보다 긴 봉 단위만 만들 수 있습니다 (5분봉 CSV면 5·15분봉만 비교).
- 투자 조언이 아니며, 레버리지 상품은 원금 이상 손실이 날 수 있습니다.
