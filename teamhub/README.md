# TeamHub — 사내 캘린더 & 업무지시 시스템

전 직원이 웹 브라우저(PC/모바일)로 접속해서 사용하는 사내 협업 프로그램입니다.

## 주요 기능

| 메뉴 | 기능 |
|---|---|
| 🏠 홈 | 오늘 일정, 내 할 일, 업무 현황(대기/진행/지연/완료), 내가 지시한 미완료 업무 수 |
| 📅 캘린더 | 월간 달력, 일정 등록/수정/삭제, 종일 일정, 색상, 공개 범위(전사/부서/나만), 업무 마감일 함께 표시 |
| 📋 업무 | 업무 지시(여러 명 동시 지시 가능), 우선순위·마감일, 상태 변경(대기/진행중/완료/보류), 코멘트, 받은/지시한/전체(관리자) 보관함, 검색 |
| 🔔 알림 | 업무를 받았을 때, 상태가 바뀌었을 때, 코멘트가 달렸을 때 알림 (30초마다 갱신) |
| 👥 직원관리 | (관리자) 직원 등록, 아이디/비밀번호 설정·변경, 부서/직급/권한/메일 수정, 퇴사 처리(비활성화) |
| 📧 Outlook 연동 | 업무 지시 메일 발송, **메일에서 바로 [진행 시작]/[완료 처리]**, 완료 시 지시자에게 메일, 매일 아침 마감/지연 리마인더, 업무별 메일 발송 기록 |

### 권한
- **직원**: 일정 등록, 본인 일정 수정/삭제, 업무 지시, 받은 업무 상태 변경·코멘트
- **지시자**: 본인이 지시한 업무 내용 수정·삭제
- **관리자**: 모든 일정/업무 관리, 전체 업무 조회, 직원 관리
- **아이디/비밀번호 설정·변경은 관리자만 가능**합니다. 직원은 본인 비밀번호를 직접 바꿀 수 없으며 관리자에게 요청합니다.

## 실행 방법

```bash
cd teamhub
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://localhost:8100` 접속.
같은 사내 네트워크의 직원들은 `http://<서버PC의 IP>:8100` 으로 접속하면 됩니다.

### 최초 로그인
- 아이디: `admin`
- 비밀번호: `admin1234` (환경변수 `TEAMHUB_ADMIN_PASSWORD` 로 최초 생성 시 변경 가능)

**로그인 후 반드시 우측 상단 메뉴 → 비밀번호 변경을 해주세요.**
그 다음 👥 직원관리에서 직원별 아이디/비밀번호/Outlook 메일 주소를 설정해 전달하면 됩니다.

### 환경변수
| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `8100` | 서버 포트 |
| `TEAMHUB_DB` | `teamhub/teamhub.db` | 데이터베이스 파일 경로 (이 파일만 백업하면 됨) |
| `TEAMHUB_ADMIN_PASSWORD` | `admin1234` | 최초 관리자 비밀번호 |

## 📧 Outlook 메일 연동

### 동작 방식
1. 업무를 지시하면 담당자의 Outlook으로 **[업무지시] 메일**이 갑니다. 메일 안의 **▶ 진행 시작 / ✔ 완료 처리** 버튼으로 TeamHub에 로그인하지 않고도 바로 상태를 바꿀 수 있습니다.
2. 담당자가 상태를 바꾸면(웹이든 메일이든) **지시자에게 [업무완료] 등의 메일**이 가서, 업무를 했는지 안 했는지 바로 확인할 수 있습니다.
3. 매일 아침(기본 9시) **담당자에게는 마감일이 오늘이거나 이미 지난 미완료 업무 리마인더**, **지시자에게는 기한이 지났는데 끝나지 않은 업무 요약**을 보냅니다.
4. 업무 상세 화면과 👥 직원관리 하단에서 메일 발송 기록(발송/실패/미설정)을 볼 수 있습니다.

> 메일의 버튼 링크는 업무·담당자별로 서명되어 위조할 수 없고, 링크를 열면 확인 화면이 먼저 나오므로 Outlook 보안 링크 검사(Safe Links)가 링크를 미리 열어도 상태가 바뀌지 않습니다.

### 설정
발송용 Microsoft 365(Outlook) 계정을 하나 준비하고(예: `teamhub@회사도메인`), 환경변수를 설정한 뒤 서버를 시작합니다.

```bash
export TEAMHUB_SMTP_USER="teamhub@company.com"
export TEAMHUB_SMTP_PASSWORD="계정 비밀번호 또는 앱 비밀번호"
export TEAMHUB_BASE_URL="http://192.168.0.10:8100"   # 직원들이 접속하는 주소 (메일 버튼 링크에 사용)
python app.py
```

| 변수 | 기본값 | 설명 |
|---|---|---|
| `TEAMHUB_SMTP_USER` / `TEAMHUB_SMTP_PASSWORD` | (없음) | 발송 계정. 없으면 메일은 보내지 않고 기록만 '미설정'으로 남음 |
| `TEAMHUB_SMTP_HOST` / `TEAMHUB_SMTP_PORT` | `smtp.office365.com` / `587` | Outlook.com 개인 계정은 `smtp-mail.outlook.com` |
| `TEAMHUB_MAIL_FROM` | SMTP 계정 | 보낸 사람 주소 |
| `TEAMHUB_BASE_URL` | `http://localhost:8100` | 메일 속 링크 주소 — **반드시 직원 PC에서 접속 가능한 주소로 설정** |
| `TEAMHUB_REMINDER_HOUR` | `9` | 리마인더 발송 시각(0~23시) |

Microsoft 365 관리자 센터에서 발송 계정의 **SMTP 인증(Authenticated SMTP)** 이 켜져 있어야 합니다.
(사용자 → 해당 계정 → 메일 → 이메일 앱 관리 → "인증된 SMTP" 체크). MFA를 쓰는 계정이면 앱 비밀번호를 사용하세요.
설정 후 👥 직원관리 하단의 **테스트 메일 보내기**로 확인할 수 있습니다.

## 구성
- `app.py` — FastAPI 백엔드 + SQLite DB (별도 DB 서버 설치 불필요)
- `mailer.py` — Outlook(SMTP) 메일 발송, 메일 버튼 서명, 일일 리마인더
- `static/index.html` — 프론트엔드 (단일 파일, 외부 라이브러리 없음)

> 회사 외부(인터넷)에서 접속하게 하려면 HTTPS(예: Nginx + 인증서) 뒤에 두고 운영하는 것을 권장합니다.
