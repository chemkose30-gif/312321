# 네이버 블로그 3개 운영 키트

| 폴더 | 블로그 | 콘셉트 | 어투 | 쇼핑커넥트 |
|---|---|---|---|---|
| `blog-A-자취생활` | A | 자취·1인가구 생활 꿀팁 | 친구한테 말하듯 (해요체 + 가벼운 구어) | 자취템, 소형 생활용품 |
| `blog-B-연예인패션` | B | 연예인 가방·옷·액세서리 정보 (애드포스트 메인) | 정보 전달 + 가벼운 해요체 | 비슷한 가성비 제품 |
| `blog-C-가전디지털` | C | 가전·디지털 비교 | 분석형 (합니다/해요 혼용, 표·수치 위주) | 계절가전, 소형가전, 디지털기기 |

> `blog-B-살림` 폴더는 이전 B 기획(살림)이라 보관용으로 남겨두었습니다.

## 파일 구성
- `common/홈판-글쓰기-가이드.md`: 세 블로그 공통으로 적용할 홈판 노출용 구조 규칙
- `blog-*/가이드.md`: 블로그별 톤, 주제 목록, 금지사항
- `blog-*/템플릿.md`: 글을 쓸 때 그대로 복사해서 채우는 틀
- `blog-*/샘플-01.md`: 가이드대로 작성한 완성 샘플

## 샘플 안의 표기
- `📷 [사진 N]` 자리에는 직접 찍은 사진을 넣습니다. 무엇을 어떻게 찍을지 적어두었습니다.
- `🛒 [쇼핑커넥트]` 자리에는 쇼핑커넥트에서 발급받은 상품 링크 카드를 넣습니다.
- `[ ]`로 감싼 부분은 실제 정보(상품명, 가격, 본인 경험)로 바꿔야 하는 부분입니다.

## 3개 운영 원칙
1. 같은 글을 바꿔 쓰는 방식으로 돌려쓰지 않습니다. 주제가 겹쳐도 각도와 내용을 완전히 다르게 씁니다.
2. 다른 사람 블로그·후기의 사진은 쓰지 않습니다. 저작권 문제가 있고, 중복 이미지는 저품질 원인이 됩니다.
3. 블로그끼리 서로 링크를 몰아주지 않습니다.
4. 쇼핑커넥트 링크가 있는 글에는 글 맨 위에 수수료 고지 문구를 넣습니다(공정위 규정).
