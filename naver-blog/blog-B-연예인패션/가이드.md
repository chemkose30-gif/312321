# 블로그 B 가이드: 연예인 패션 (가방·옷·액세서리 정보)

## 콘셉트
- 연예인이 공항, 행사, 방송, 드라마에서 입고 든 아이템의 **브랜드·제품명·가격**과 **비슷한 가성비 제품**을 정리하는 블로그
- 수익: 애드포스트(메인) + 쇼핑커넥트(비슷한 제품 추천)

## 작업 흐름 (역할 분담)
| 단계 | 담당 | 내용 |
|---|---|---|
| 1. 화제 착장 찾기 | Claude | 언론사 기사 검색으로 최근 공항·행사·방송 착장 기사 링크 목록 정리 (인스타는 직접 확인) |
| 2. 착장 정보 찾기 | 운영자 | 브랜드, 제품명, 가격, 공식 판매처 확인 → `착장-정보-양식.md` 작성 |
| 3. 글 작성 | Claude | 양식 내용을 받아 템플릿에 맞춰 글 완성 |
| 4. 확인·발행 | 운영자 | 정보 최종 확인, 이미지 넣고 발행 |

## 제목 공식
> **운영자 결정 (2026-11-10): 기본은 홈판형 제목.** 피드에서 눌러보고 싶은 문장형으로 쓰고, 검색형 제목은 노션 "완성 글"에 대안으로 함께 적어 발행 때 고르게 합니다.

- 홈판형 (기본): `[연예인명]이 [상황]에 [입고/들고] 나온 [아이템], [궁금증 유발 문구]`
  - 예: "변우석이 공항에 입고 나온 패딩, 가격 알아보니"
  - 20~30자, 연예인명은 맨 앞. 과장·낚시 표현("충격", "난리") 금지.
- 검색형 (대안):
- `[연예인명] [상황] [아이템] 정보, [브랜드] [제품명] 가격`
  - 예: "[연예인명] 공항패션 가방 정보, [브랜드] [제품명] 가격"
- `[드라마명] [회차] [연예인명] [아이템] 브랜드 정보`
  - 예: "[드라마명] 5화 [연예인명] 코트 브랜드 정보"
- 연예인 이름과 아이템을 **제목 앞쪽**에 둡니다. 검색어 그대로입니다.
- 20~35자. 과장 표현("완판", "품절 대란")은 사실일 때만 씁니다.

## 이미지 원칙 (가장 중요)
- **운영자 결정: 언론사 기사 사진을 출처 표기와 함께 사용합니다.**
  - 출처 표기는 사용 허락이 아닙니다. 무단 사용으로 신고되거나 사용료를 청구받을 수 있으며, 그 위험은 운영자가 감수합니다.
  - 글당 기사 사진 5~7장 (운영자 결정). 장수가 많을수록 신고 위험이 커집니다.
  - 원본 그대로(자르기·합성·워터마크 제거 금지), 사진 바로 아래에 `출처: [언론사] [기자명] 기자` + 기사 링크.
  - 인스타 사진과 방송 캡처는 쓰지 않습니다.
  - 사진 사용 중단 요청이 오면 즉시 삭제합니다.
- 나머지 이미지는 아래로 채웁니다:
  - 쇼핑커넥트 상품 카드 이미지
  - 브랜드가 보도·홍보용으로 공개한 제품 이미지 (사용 조건 확인)
  - 직접 찍은 매장·실물 사진
  - 직접 만든 정리 이미지 (아이템 이름·가격을 넣은 카드)
- 기사 사진마다 **원본 기사 링크**를 함께 겁니다.

## 정보 정확성
- 확인된 정보: "○○ 착용 제품은 [브랜드] [제품명]입니다" (출처: 브랜드 공식 계정, 소속사, 신뢰할 수 있는 기사)
- 추정 정보: "**[브랜드] [제품명]으로 추정**됩니다", "**비슷한 디자인**의 제품입니다"
- 가격은 "작성일 기준 공식 판매가"로 적고 날짜를 남깁니다.
- 연예인 사생활, 외모 평가, 루머는 쓰지 않습니다.

## 발행량
- 블로그당 하루 6~10편까지. 그 이상은 블로그를 하나 더 만들어 나눕니다.
- 같은 착장을 제목만 바꿔 여러 편 쓰지 않습니다. 한 착장 = 한 글.
- 발행 간격은 1~2시간 이상 띄웁니다.
