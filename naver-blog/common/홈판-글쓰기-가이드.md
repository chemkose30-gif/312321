# 네이버 홈판 노출용 글쓰기 가이드 (공통)

> 홈판(네이버 앱 메인 홈피드)은 AI 추천으로 노출됩니다. 핵심 지표는 **클릭률(제목+대표사진)**, **체류시간**, **반응(공감·댓글·저장)**입니다.
> 아래 수치는 홈판 글에서 흔히 보이는 패턴을 정리한 권장 범위입니다. 절대 규칙은 아닙니다.

## 1. 제목
- 길이: 공백 포함 **20~35자**
- 핵심 키워드는 **앞쪽 10자 안에** 넣습니다.
- 잘 먹히는 유형:
  - 숫자형: "원룸 외풍 막는 법 5가지"
  - 경험형: "3주 써보고 정착한 ○○"
  - 비교형: "A vs B, 전기요금까지 비교해봤어요"
  - 문제해결형: "겨울 빨래 냄새, 이렇게 하니 사라졌어요"
- 피할 것: 과장 낚시("충격", "무조건"), 특수문자 남발, 키워드 나열형 제목

## 2. 대표사진(썸네일)
- 홈판 클릭률의 절반 이상을 좌우합니다.
- 밝고 선명한 **실물 사진** + 필요하면 짧은 문구(10자 이내)를 얹습니다.
- 정사각형 또는 4:3 비율로 찍고, 피사체를 가운데 크게 둡니다.
- 스톡사진이나 다른 블로그 사진은 쓰지 않습니다.

## 3. 본문 구조 (기본 틀)
```
[수수료 고지 문구]          ← 쇼핑커넥트 링크가 있을 때만
[도입 3~5줄]                ← 공감되는 상황 + 이 글에서 얻을 것
[요약 박스]                 ← 결론 먼저 3줄 (인용구 사용)
[소제목 1] 사진 + 설명
[소제목 2] 사진 + 설명
[소제목 3] 사진 + 설명 + 🛒 상품
[소제목 4] 주의사항/실패담
[정리] 한 줄 요약 + 질문 유도
[태그]
```

| 항목 | 권장 범위 |
|---|---|
| 전체 글자 수 | 1,500~2,500자 (공백 제외) |
| 소제목 | 4~6개 (인용구 또는 굵은 글씨) |
| 사진 | 8~15장, 소제목마다 최소 1장 |
| 문단 | 1~3줄마다 줄바꿈 (모바일 기준) |
| 쇼핑커넥트 링크 | 글당 1~3개, 본문 중후반 |
| 태그 | 8~15개 |

## 4. 문장 스타일
- 모바일에서 한 줄이 15~20자 정도 되도록 짧게 끊습니다.
- 한 문단에 한 가지 내용만 씁니다.
- 핵심 문장은 **굵게** 또는 색으로 강조하되, 한 화면에 1~2개까지만 씁니다.
- "제가 해보니", "3일 써보니"처럼 **직접 경험한 표현**을 꼭 넣습니다. 네이버는 경험 정보를 우대합니다.
- 이모티콘은 소제목이나 강조에 가볍게만 씁니다.

## 5. 키워드
- 메인 키워드 1개, 서브 키워드 2~3개를 정합니다.
- 메인 키워드는 제목 1회, 도입부 1회, 본문에 자연스럽게 3~5회 넣습니다.
- 같은 단어를 억지로 반복하면 오히려 불리합니다.

## 6. 마무리
- 3줄 이내로 정리합니다.
- 질문으로 끝내서 댓글을 유도합니다. 예: "여러분은 어떤 방법 쓰세요?"
- 같은 블로그 안의 관련 글 1~2개를 링크합니다. 체류시간에 도움이 됩니다.

## 7. 쇼핑커넥트 삽입 규칙
- 글 **맨 위**에 고지 문구를 넣습니다.
  > 이 포스팅은 네이버 쇼핑커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.
- 정보 → 경험 → 상품 순서로, 상품은 **문제를 해결하는 수단**으로 소개합니다.
- 상품 소개만 있는 글은 홈판에 잘 오르지 않습니다. 정보 비중을 70% 이상으로 유지합니다.
- 써보지 않은 상품을 써본 것처럼 쓰지 않습니다.

## 8. 발행 습관
- 블로그당 주 3~5회, 비슷한 시간대에 발행합니다.
- 발행 직후 1시간 안에 공감·댓글이 붙으면 유리하므로, 이웃 소통을 꾸준히 합니다.
- 발행 후 제목이나 대표사진을 여러 번 바꾸지 않습니다.

## 9. 금지사항 (저품질 원인)
- 다른 글 복사 및 짜깁기, 같은 글 여러 블로그에 게시
- 남의 사진 사용, 같은 사진 재사용
- 외부 링크 과다, 상품 링크만 잔뜩 넣은 글
- 키워드 반복 도배, 본문과 상관없는 태그
