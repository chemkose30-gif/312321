## B 블로그 작업 방식
1. Claude: 언론사 기사 검색으로 화제 착장 후보를 찾아 노션 표에 추가
2. 운영자: 착장 브랜드·제품명·가격을 확인해 노션 페이지 양식에 기입하고, 기사 사진과 출처(언론사·기자명·링크)를 첨부한 뒤 상태를 "착장 확인"으로 변경
3. Claude: "착장 확인" 상태인 페이지의 "완성 글" 칸에 글을 작성하고 상태를 "글 작성 완료"로 변경
4. 운영자: 최종 확인 후 발행하고 상태를 "발행", 발행 URL 입력

- 노션 작업실: https://app.notion.com/p/413782870d12810ebea1f756fa056faf
- 노션 착장 관리 DB 데이터소스: `collection://d451106c-f27d-4e36-a421-02ead659d024`
- 템플릿·가이드: `naver-blog/blog-B-연예인패션/`

## 운영자가 정한 사항
- 기사 사진을 **글당 5~7장**, 사진 바로 아래 `출처: [언론사] [기자명] 기자 (기사 링크)` 표기로 사용.
  - 출처 표기는 사용 허락이 아니라는 점, 신고·사용료 청구 위험은 이미 안내했고 운영자가 감수하기로 함.
- 하루 발행량: **블로그당 최대 10편, 3개 합쳐 30편 이내** (2026-11-09 확정). 운영자는 30~50편을 원했으나 같은 운영자 3계정 동시 저품질·기사 사진 신고 위험을 안내한 뒤 10편으로 정함. 2~3주 노출·저품질 여부를 보고 조정.
- 글 스타일: **홈판형이 기본** (2026-11-10 확정). 제목은 홈판형 문장으로 쓰고, 검색형 제목은 대안으로 함께 제시. 본문은 `common/홈판-글쓰기-가이드.md` 구조(짧은 줄, 요약 박스, 소제목 4~6개, 질문 마무리). 확인 안 된 정보는 "추정"과 이유를 함께 표기.
- 기사 사진 역할 분담: Claude는 기사를 열어 쓸 사진 5~7장을 고르고 출처 줄(언론사·기자명·링크)을 노션 페이지에 정리, 사진 저장·삽입은 운영자가 직접 함.
