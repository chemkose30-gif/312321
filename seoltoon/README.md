# 썰툰 스튜디오

대사를 쓰고, 그림을 그리고, 목소리를 얹어 **한 편의 썰툰 영상**으로 뽑아내는 웹 앱입니다.
서버도 API 키도 필요 없이 **브라우저 안에서 전부 처리**됩니다.

## 실행 방법

방법 1 — 그냥 파일 열기
```
seoltoon/index.html 을 크롬(또는 엣지)으로 열기
```

방법 2 — 로컬 서버로 열기
```bash
python3 -m http.server 8000
# http://localhost:8000/seoltoon/ 접속
```

방법 3 — 이 저장소의 FastAPI 서버와 함께
```bash
pip install -r requirements.txt
python main.py
# http://localhost:8765/seoltoon/ 접속
```

## 만드는 순서

1. **대본 일괄 입력** — 한 줄에 한 컷씩 붙여넣으면 씬이 자동으로 만들어집니다.
   - `친구A: 야 그거 봤어?` → 화자 + 대사 (화자별 색깔 자동 지정)
   - `# 그날 밤, 비가 왔다` → 나레이션 컷
   - 대사 길이에 맞춰 컷 길이(초)도 자동 계산됩니다.
2. **그림** — 씬을 고르고 가운데 캔버스에 그립니다.
   - 펜 / 형광펜 / 지우개 / 이모지 스탬프, 굵기·색상, 되돌리기(Ctrl+Z)
   - 배경 프리셋: 그라데이션 · 집중선 · 밤하늘 · 노트 줄무늬 · 스크린톤
   - 사진 넣기로 직접 찍은 사진을 배경으로 쓸 수도 있습니다.
3. **대사 & 음성** — 화자 이름, 대사, 나레이션, 자막 스타일(말풍선/하단 자막/없음), 컷 길이를 조정합니다.
   - 🎤 **녹음** 버튼으로 내 목소리를 씬에 붙이면 영상에 그대로 들어갑니다.
     (음성이 대사 길이보다 길면 컷 길이가 자동으로 늘어납니다.)
   - TTS 버튼은 대사 톤을 확인하는 **미리듣기 전용**입니다. 브라우저 TTS 소리는 녹화에 담기지 않습니다.
4. **작품 설정** — BGM 파일, BGM 볼륨, 타이핑 효과, 장면 전환 페이드, 자막 크기.
5. **▶ 미리보기** 로 확인하고 **🎬 영상 만들기** 를 누르면 영상 파일이 내려받아집니다.

## 출력 사양

- 비율: 세로 9:16(1080×1920, 쇼츠·릴스) / 정사각 1:1 / 가로 16:9
- 포맷: WebM(VP9+Opus). 사파리 등 WebM 미지원 브라우저에서는 MP4로 저장됩니다.
  두 포맷 모두 유튜브·인스타그램·틱톡에 그대로 업로드할 수 있습니다.
- 녹화는 **실시간**으로 진행됩니다. 30초짜리 영상이면 만드는 데도 30초가 걸립니다.
- 음성(씬 녹음 + BGM)은 영상 트랙과 함께 하나의 파일로 합쳐집니다.

## 저장

- 작업 내용(그림·녹음 포함)은 브라우저의 IndexedDB에 **자동 저장**됩니다.
- 다른 기기로 옮기거나 백업하려면 `작품 설정 → 💾 프로젝트 저장`으로 `.seoltoon.json` 파일을 받아두고,
  `📂 불러오기`로 되돌리면 됩니다.
- 씬 한 장을 이미지로만 쓰고 싶으면 `🖼 현재 씬 PNG`를 누르세요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 (씬 목록 / 그림판 / 대사·음성 패널) |
| `style.css` | 다크 테마 스타일 |
| `app.js` | 상태 관리, 그림판, 프레임 합성(`drawFrame`), 타임라인 재생·녹화(`runTimeline`) |

## 브라우저 지원

크롬·엣지 최신 버전을 권장합니다. 영상 녹화는 `MediaRecorder` + `canvas.captureStream()`,
음성 합성은 `Web Audio API`를 사용합니다. 파이어폭스도 동작하며, 사파리는 일부 코덱이 다를 수 있습니다.
