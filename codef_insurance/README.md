# 설계사용 보험 계약정보 조회 (CODEF 내보험다보여)

설계사가 고객별 조회 링크를 만들어 보내면, 고객이 **자기 폰에서** 동의하고 본인인증을 해서
내보험다보여 계약정보를 조회합니다. 조회 결과는 설계사 화면에 쌓입니다.

## 구성
| 파일 | 설명 |
|---|---|
| `app.py` | 웹 서비스 (설계사 화면 + 고객 조회 화면) |
| `codef.py` | CODEF API 클라이언트 |
| `fetch_insurance.py` | 본인 1명 조회용 CLI |

## 실행
```bash
pip install -r requirements.txt
cp .env.example .env   # 값 채우기
uvicorn app:app --host 0.0.0.0 --port 8000
```
- 키 없이 화면만 시험: `.env` 에서 `CODEF_ENV=mock` (가짜 샘플 데이터)
- 고객이 접속해야 하므로 **HTTPS 가 적용된 공개 서버**에 올려야 합니다 (`PUBLIC_BASE_URL` 설정).

## 사용 흐름
1. 설계사: `/login` → "링크 생성" → 링크를 고객에게 문자/카톡으로 전달 (7일 유효, 1회용)
2. 고객: 동의 → 이름·생년월일·휴대폰·내보험다보여 아이디/비밀번호 입력 → PASS 또는 SMS 인증
3. 설계사: 목록에서 "결과 보기" (계약 목록 + 원본 데이터)

## 보안/개인정보 처리 방식
- 고객 내보험다보여 비밀번호는 **저장하지 않음** (인증 진행 중 RSA 암호화 값만 메모리에 최대 5분)
- 이름·생년월일·연락처·조회 결과는 `DATA_KEY` 로 **암호화 저장** (SQLite, 삭제 시 덮어씀)
- 동의 문구 버전·해시·시각·IP·마케팅 동의 여부를 함께 기록
- 고객이 동의를 철회하면 목록의 "삭제" 로 즉시 파기
- `DATA_KEY` 를 잃어버리면 저장된 데이터를 복구할 수 없으니 안전하게 따로 보관하세요.
